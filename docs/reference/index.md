## Utility

Useful functions

- [`calc_mv_dist()`](https://dicook.github.io/mulgar/reference/calc_mv_dist.md)
  : Compute Mahalanobis distances between all pairs of observations
- [`calc_norm()`](https://dicook.github.io/mulgar/reference/calc_norm.md)
  : Calculate the norm of a vector
- [`convert_proj_tibble()`](https://dicook.github.io/mulgar/reference/convert_proj_tibble.md)
  : This function turns a projection sequence into a tibble
- [`gen_vc_ellipse()`](https://dicook.github.io/mulgar/reference/gen_vc_ellipse.md)
  : Generate points on the surface of an ellipse
- [`gen_xvar_ellipse()`](https://dicook.github.io/mulgar/reference/gen_xvar_ellipse.md)
  : Ellipse matching data center and variance
- [`norm_vec()`](https://dicook.github.io/mulgar/reference/norm_vec.md)
  : Normalise a vector to have length 1
- [`pooled_vc()`](https://dicook.github.io/mulgar/reference/pooled_vc.md)
  : Compute pooled variance-covariance matrix
- [`rmvn()`](https://dicook.github.io/mulgar/reference/rmvn.md) :
  Generate a sample from a multivariate normal
- [`ggslice()`](https://dicook.github.io/mulgar/reference/ggslice.md) :
  Generate an axis-parallel slice display
- [`ggslice_projection()`](https://dicook.github.io/mulgar/reference/ggslice_projection.md)
  : Generate slice display

## Clustering

Useful functions for cluster analysis

- [`ggmcbic()`](https://dicook.github.io/mulgar/reference/ggmcbic.md) :
  Produces an mclust summary plot with ggplot
- [`hierfly()`](https://dicook.github.io/mulgar/reference/hierfly.md) :
  Generate a dendrogram to be added to data
- [`mc_ellipse()`](https://dicook.github.io/mulgar/reference/mc_ellipse.md)
  : Computes the ellipses of an mclust model
- [`som_model()`](https://dicook.github.io/mulgar/reference/som_model.md)
  : Process the output from SOM to display the map and data
